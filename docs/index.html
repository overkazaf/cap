WORKBENCH CAPABILITIES

      
Everything needed from packet capture to signature reversal

      
Engineered for mobile reverse engineers and AI coding agents — fast, native, scriptable, and bilingual out of the box.

    


    

      

        

        
Native Wails Desktop GUI

        
4 commercial themes (Obsidian Dark, Porcelain Light, Mocha, Nord), ⌘K Command Palette, collapsible nav rail, draggable SplitPane Flows inspector, and 7 integrated workspaces in a single binary.

      

      

        

        
Flicker-Free Interactive TUI

        
Launch with cap tui or cap start --tui. Double-buffered ANSI rendering, 6 inspector tabs, live / query filtering, async replay, clipboard cURL copy, theme switch, and live EN/中文 toggle.

      

      

        

        
Cap Companion Guard APK

        
33 KB signed pure-SDK APK embedded inside cap. Grants WRITE_SECURE_SETTINGS over ADB so its 3s heartbeat watchdog auto-restores Android network on USB unplug, Wi-Fi drop, or crash — even without root.

      

      

        

        
Full EN / 简体中文 Localization

        
Synchronized English and Simplified Chinese across GUI, TUI, CLI (--lang, CAP_LANG), and the Android Companion APK. Hot-switch instantaneously without restarting capture sessions.

      

      

        

        
LLM-Ready JSONL & 5-Lang Codegen

        
Strip noise headers, auto-tag sign_params, inline JSON bodies, and pipe compact JSONL straight to your coding agent — or generate runnable cURL, Python, Go, Java, and JS snippets.

      

      

        

        
Sign Inference & DeepTrace

        
Cross-request MD5/SHA/HMAC brute-force verification paired with jadx Retrofit/OkHttp source mapping, APK Manifest inspection, DEX string search, and Call Graph correlation.

      

      

        

        
Intercept Rules & Breakpoints

        
Pause matching requests in a live Held Breakpoints queue to forward edited payloads, mock responses, or drop traffic — alongside Replay, Flow Diff, and token-propagating Sequence Replay.

      

      

        

        
4-Strategy SSL Unpinning

        
Bypass pinning via Frida (14+ hooks including OkHttp3, Conscrypt, Flutter BoringSSL), APK NetworkSecurityConfig patching, Magisk cert promotion, or automatic Frida CodeShare search.

      

    

  







  

    

      
SELF-HEALING ANDROID CAPTURE

      
Never leave your test phone stranded without internet

      
Cap embeds com.overkazaf.cap.companion directly inside the Go binary and deploys it automatically on connect.

    


    

      

        01 · DEPLOY
        
Auto-Installed via ADB

        
cap android connect pushes the embedded 33 KB signed APK, grants WRITE_SECURE_SETTINGS, and whitelists battery optimization automatically.

      

      

        02 · CERT
        
CA Cert (Android 7–15)

        
Uses mount --bind, Magisk, or /system remount on rooted phones, and launches Android KeyChain directly via Companion MainActivity on non-rooted devices.

      

      

        03 · WATCHDOG
        
3s Heartbeat Probe

        
ProxyGuardService continuously probes proxy_host:proxy_port every 3 seconds with a persistent notification and one-tap Restore Network action.

      

      

        04 · RESTORE
        
Autonomous Teardown

        
3 missed probes, USB unplug, reboot (BootReceiver), or desktop StopProxy/Shutdown cleanly clears http_proxy and VPN iptables rules.

GET STARTED IN SECONDS

      
Build & run cap locally

      
Compiles a self-contained binary with embedded Svelte GUI assets and the signed Android Companion Guard APK.

    


    

      

        

          
          
          
          
        

        
      


      


git clone https://github.com/overkazaf/cap.git
cd cap

# Build frontend, verify asset SHA-256, and compile Wails desktop binary
make assets && make build

# Launch Desktop GUI or Full-Screen Interactive TUI
./dist/cap gui
./dist/cap tui --live

      


      


git clone https://github.com/overkazaf/cap.git
cd cap
go build -o dist/cap ./cmd/cap

# Start live MITM proxy inside the interactive TUI
./dist/cap start --tui -a 0.0.0.0:8080

      


      


# 1. Start MITM proxy inside full-screen TUI (or use ./dist/cap gui)
./dist/cap start --tui -a 0.0.0.0:8080

# 2. Query saved flows or export for LLM / coding agents
./dist/cap flows --host api.example.com --method POST -n 20
./dist/cap export --flow f1 -l python
./dist/cap export -f agent | pbcopy

# 3. Switch CLI/TUI language anytime
./dist/cap tui --lang zh

      


      


# One-command Android setup: proxy + CA cert + Companion Guard Watchdog
./dist/cap android connect

# Inspect device identity, CA cert trust, and Companion Guard status
./dist/cap android status

# Verify or remove CA cert / clean disconnect (also auto-restores on USB unplug)
./dist/cap android cert --check
./dist/cap android disconnect

      


      
Requirements: Go 1.27+, Node.js 18+ (for GUI assets). macOS needs Xcode Command Line Tools; Linux GUI needs libgtk-3-dev & libwebkit2gtk-4.0-dev.
